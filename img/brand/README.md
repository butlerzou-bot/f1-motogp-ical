# 品牌 logo 素材

`fetch_logos.py` 合成每站「赛事 logo」徽标时用的系列 wordmark（白色单色版）。

| 文件 | 说明 |
| --- | --- |
| `f1-logo.svg` / `f1-logo.png` | Formula 1 现行标志（2018 年启用的 F/1 + 速度线造型），官方红 `#E10600`，透明底，PNG 2000×500 |
| `f1-logo-white.svg` / `f1-logo-white.png` | F1 白色单色版（徽标用这一版） |
| `motogp-logo.svg` / `motogp-logo.png` | MotoGP 现行字标（2025 赛季启用），深色 `#111111`，透明底，PNG 2000×320 |
| `motogp-logo-white.svg` / `motogp-logo-white.png` | MotoGP 白色单色版（徽标用这一版） |

## 来源

- **F1**：Simple Icons 的 `f1` 图标（CC0）<https://cdn.jsdelivr.net/npm/simple-icons@latest/icons/f1.svg>，按官方品牌红 `#E10600` 上色并裁到图形边界。
- **MotoGP**：MotoGP 官方静态资源 <https://static.dorna.com/assets/logos/mgp/brand/mgp-logo-on-light.svg>（深色版）与 `mgp-logo-on-dark.svg`（白色版）；去掉文件头 `<?xml?>` 与 `width/height` 的 mm 尺寸，只保留 viewBox。

## 使用注意

SVG 为矢量，可任意放大；PNG 为透明底、已按内容裁边，2000px 宽。

F1 与 MotoGP 均为其各自权利人的注册商标，此处仅作个人/编辑用途（订阅日历等非商业场景）。商业使用、或暗示与官方存在关联前请先取得授权，并遵守各自的品牌使用规范（F1 Brand Guidelines / MotoGP Brand Guidelines）。
